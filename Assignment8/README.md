## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Two-Dimensional Arrays:**  
A matrix can be represented in Java using a two-dimensional array with rows and columns.

**2. Nested Loop Traversal:**  
Nested loops are used to access each element by its row and column index.

**3. Transpose:**  
The transpose of a matrix is formed by swapping its rows and columns.

**4. Row Sum:**  
The sum of a row is calculated by adding all elements in that row.
