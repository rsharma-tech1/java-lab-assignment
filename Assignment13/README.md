## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. String:**  
String is a sequence of characters in Java.

**2. String Methods:**  
length() returns the number of characters, indexOf() finds a character position and toUpperCase() converts letters to uppercase.

**3. charAt():**  
charAt(index) returns the character at the specified index.

**4. Palindrome:**  
A palindrome reads the same from left to right and right to left.

**5. substring():**  
substring() extracts a portion of a string between specified indexes.
