## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Insertion Sort:**  
Insertion sort builds a sorted portion of an array by taking each next element and inserting it into its correct position.

**2. Shifting:**  
A shift moves an existing array value one position to the right to make room for the key value.

**3. Increasing Order:**  
The algorithm compares values with the key and shifts larger values until the correct insertion position is found.
