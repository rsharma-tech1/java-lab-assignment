## 1. Experiment Title

Star and Number Patterns in Java.

## 2. Aim

Use a loop inside another loop to print stars and numbers in rows.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE: Visual Studio Code (VS Code)

## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Nested Loops:**  
A nested loop is a loop placed inside another loop. The outer loop controls rows and the inner loop controls the items printed in each row.

**2. Pattern Printing:**  
Changing the inner loop limit produces square, triangle and inverted-triangle patterns.

**3. System.out.print():**  
System.out.print() displays content without moving to a new line, allowing values to be printed on the same row.
