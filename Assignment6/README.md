## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Reverse Traversal:**  
An array can be printed in reverse by starting at the last index and decreasing the index to zero.

**2. Finding the Minimum:**  
Initialize the smallest value with the first array element, then compare each element and update the value and index when a smaller value is found.

**3. Nested Loops:**  
Nested loops can compare pairs of array elements to find duplicate values.
