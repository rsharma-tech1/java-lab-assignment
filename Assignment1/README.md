## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Output Statement:**  
System.out.println() is used to display text and values on the console. It prints the output on a new line.

**2. Variables:**  
Variables are named memory locations used to store data. Java data types used in this experiment include int for integer values, double for decimal values, char for a single character and String for a sequence of characters.

**3. Arithmetic Operators:**  
Java provides + for addition, - for subtraction, * for multiplication, / for division and % for modulus (remainder).

**4. Constant:**  
The final keyword is used to declare a constant whose value cannot be changed after initialization.

**5. Circle Formulas:**  
Area = PI × radius × radius; Perimeter = 2 × PI × radius.
