## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. switch Statement:**  
A switch statement selects one branch from several possible cases based on the value of an expression.

**2. ArrayList:**  
ArrayList is a resizable list in Java that stores elements and can grow or shrink dynamically.

**3. ArrayList Methods:**  
add() inserts an element, size() returns the number of elements, get() reads an element, set() updates an element and remove() deletes an element.
