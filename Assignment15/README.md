## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. StringBuilder:**  
StringBuilder is a mutable sequence of characters. Its contents can be changed without creating a new String object each time.

**2. append():**  
append() adds text or values at the end of a StringBuilder.

**3. insert():**  
insert() adds text at a specified position.

**4. deleteCharAt():**  
deleteCharAt() removes the character at the specified index.

**5. length():**  
length() returns the number of characters in the StringBuilder.
