## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Time Complexity:**  
Time complexity describes how the number of operations grows as the input size grows.

**2. Single Loop:**  
A loop that runs n times has linear time complexity, O(n).

**3. Nested Loops:**  
Two loops each running n times perform n × n iterations and have O(n²) time complexity.

**4. Halving Loop:**  
Repeatedly dividing a value by two takes logarithmic time, O(log n).
