## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Bubble Sort:**  
Bubble sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

**2. Selection Sort:**  
Selection sort repeatedly selects the smallest remaining element and places it at the next sorted position.

**3. Swaps:**  
A swap exchanges the positions of two values. The swap count records how many exchanges take place.
