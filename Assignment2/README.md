## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. if-else Statement:**  
The if-else statement executes one of two blocks depending on whether a condition is true or false.

**2. else-if Ladder:**  
An else-if ladder checks multiple conditions in sequence and executes the first matching branch.

**3. Modulus Operator:**  
The % operator returns the remainder. A number divisible by 2 has remainder 0 and is even.

**4. Loops:**  
A for loop repeats a block of code a specified number of times.

**5. Leap Year Rule:**  
A year is a leap year if it is divisible by 4 but not by 100, or if it is divisible by 400.
