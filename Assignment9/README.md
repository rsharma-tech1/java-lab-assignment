## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Matrix Rows:**  
A row contains the elements that share the same first index in a two-dimensional array.

**2. Matrix Columns:**  
A column contains the elements that share the same second index.

**3. Column Sum:**  
A column sum is found by keeping the column index fixed and adding values across all rows.

**4. Conditional Counting:**  
A counter can be increased whenever a matrix element satisfies a given condition.
