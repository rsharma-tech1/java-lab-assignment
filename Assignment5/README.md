## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Arrays:**  
An array stores multiple values of the same data type in a single variable.

**2. Array Index:**  
Array indexing starts at 0. The length property gives the number of elements in an array.

**3. Traversal:**  
Array traversal means visiting each element, commonly using a for loop.

**4. Counting and Aggregation:**  
A loop can maintain a running sum, largest value or count based on a condition.
