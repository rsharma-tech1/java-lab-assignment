## 4. Theory

Java is a high-level, object-oriented programming language.

The following concepts are used in this experiment:

**1. Methods:**  
A method is a block of code that performs a task and can be called when needed.

**2. Parameters and Return Values:**  
Parameters pass values to a method. A return statement sends a result back to the calling method.

**3. Factorial:**  
The factorial of n is the product of all positive integers from 1 to n.

**4. Combinations and Permutations:**  
nCr = n! / (r! × (n-r)!) and nPr = n! / (n-r)!.
